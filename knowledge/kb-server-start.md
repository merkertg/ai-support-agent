Вымышленная статья учебного проекта. Описывает типичные причины, по которым
служба TechFlow Server останавливается сразу после обновления.

## Признаки проблемы

После установки новой версии служба TechFlow Server запускается и через
несколько секунд останавливается. Веб-интерфейс недоступен, а в журнале
`server.log` последней строкой указана ошибка инициализации.

## Частые причины

- Файл `config.yaml` остался в формате предыдущей версии. Новая версия
  не запускается, пока конфигурация не обновлена командой
  `techflow-server config migrate`.
- Порт 8443 занят другим процессом, например старой копией службы.
- Срок лицензии истёк или ключ лицензии отозван: при запуске сервер
  проверяет лицензию и останавливается, если она недействительна.
- У учётной записи службы нет прав на каталог данных после обновления.

## Что проверить

1. Выполните `techflow-server config check` и исправьте указанные строки.
2. Проверьте, что порт 8443 свободен.
3. Сверьте статус и срок действия лицензии клиента.
4. Найдите в `server.log` первую строку с уровнем `ERROR` после запуска.

## Какие сведения запросить у клиента

Попросите номер версии до и после обновления, операционную систему, точное
время последнего запуска и фрагмент `server.log` за эту минуту. Пароли,
ключи лицензии и персональные данные присылать не нужно.
